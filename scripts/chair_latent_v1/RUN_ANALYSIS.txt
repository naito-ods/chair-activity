Annotation-free continuous latent study, separate from existing DTW labels

This folder compares compact masked AE/VAE models, conditional linear latent
models, semantic HP/RPM/order summaries, and local observed-value predictors.
It borrows cryoDRGN's continuous-representation/return-to-observations idea;
it does not apply cryoDRGN's cryo-EM projection likelihood to chair logs.
Latent dimension is not a number of treatment classes. No annotations or
existing cluster labels are learning targets. Prediction improvement alone
does not demonstrate a new recurring operation pattern.

Environment: existing Python3.10 chair_c31 venv; NumPy, pandas, SciPy,
scikit-learn, matplotlib. Torch/UMAP are not required. No GPU is required.
Use OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 to bound memory/CPU threads.
All commands below are from the repository root; local outputs are outside
the repository under its parent C31/Output. Clinical input data are required
locally and must never be committed. Use NEW output directories; preserve
every freeze, failed result, correction, and code snapshot.

Read AGENTS.md. Required original compact inputs are the existing exports:
../Output/chair_hp_sequence_300_v3_20261104/{case_manifest,hp_intervals,hp_runs,
observations,hp2_points,case_patterns}.csv. Original preprocessed source and
meta files must match the SHA256 values recorded by that manifest.
Some scripts intentionally use this fixed original-cohort path and verified
case counts; this is a reproducible cohort-specific research workflow, not
a generic package for arbitrary cohorts. Do not change counts silently.

The historical narrative report generator is retained locally and excluded
from the public code-only package because it embeds run-specific conclusions.
For a new study, write the report from its verified tables and independent
review; do not copy a historical conclusion into a new result.

Every numeric estimate is a model output. Missing source observations remain
NaN; no forward filling/interpolation is used to manufacture raw waveforms.
Read individual code timestamps when masking signals: shared RPM row time
can otherwise leak hidden torque/pedal observations at bin boundaries.
All public files here are code/re-execution guidance only. Case ledgers,
data, generated plots/reports, evaluation reviews, and notification addresses
remain local. No clinical treatment or external patient validation is claimed.
