CHAIR LOG · PORTABLE EDITION 1.1

Windows・macOSで使う

このフォルダ一式を展開し、起動ファイルを開きます。処置は日本語、器具は指定の英語40種類です。

1. 移行用ZIPを作る

元のPCで新しいGUIを開き、移したい症例を選択して「別PCへ移す ZIP」を押します。「全保存症例をまとめる」を選択すると、保存済み症例をまとめます。下書きのままでも移せます。

移行ZIPにはアプリ・原ログ・注釈の保存履歴が入ります。完成した注釈だけを解析する「最終出力ZIP」とは用途が異なります。動画は入らないため、必要な動画を別にコピーします。

2. 別のPCで準備する

  1. ZIPをUSBなどで移し、フォルダ全体を展開してください。ZIP内から直接起動せず、展開後の ChairLogAnnotator フォルダを使用します。
  2. Pythonがない場合は Python公式サイト から現在提供されている通常版をインストールします。このアプリはPython 3.10以上が必要です。追加のpip/npmインストール、GPUは不要です。
  3. Chrome・Edge・Firefoxなどのブラウザを用意します。

3. 起動する

OS開くファイル
WindowsSTART_WINDOWS.bat をダブルクリック
macOS（Intel / Apple Silicon）START_MAC.command をダブルクリック

ブラウザが自動で開きます。編集中は起動時の端末ウィンドウを開いたままにしてください。終了時は端末で Ctrl+C を押します。毎回ローカルの空いているポートを使用するので、古いURLを別のPCへコピーする必要はありません。

データ入りの移行ZIPでは、同梱された C31 が自動で選択されます。アプリだけの配布ZIPの場合は、chair_export を含むデータフォルダを選びます。フォルダ選択画面が出ない環境では端末にパスを入力できます。

Python同梱の .exe / .app ではありません。起動するPCにもPythonが必要です。Windows/macOS実機での起動確認はまだ行っておらず、Linuxで配布・復元・保存・出力を検証しています。

4. 編集の続きと保存

保存先は選択したデータフォルダの Output/chair_continuous_annotations_v1 です。移行ZIPから展開した場合は ChairLogAnnotator/C31/Output/chair_continuous_annotations_v1 に保存されます。器具名・処置名・確認根拠・境界の誤差・保存履歴を保持します。

動画は同じファイルを選び直してください。ファイル名と時刻オフセットは注釈に保持されます。オンライン同期や、複数PCで別々に編集した履歴の自動統合はありません。作業を移すときは保存して移行ZIPを作り、別の新規フォルダへ展開してください。

自分でデータをコピーする場合

必要な症例の .dat を、日付・チェアのフォルダ構造を保ってコピーします。C31全体や既存の学習結果を移す必要はありません。従来の注釈を参照する場合はCSVもコピーします。

C31/
  chair_export/
    日付/チェア/Chair_log_seq_番号.dat
  ChairLog_annotations1438_1479.csv    ← 既存注釈を参照する場合
  Output/
    chair_continuous_annotations_v1/  ← 続きから編集する場合はフォルダ全体

既存の保存フォルダを新しい環境へ移す場合、原ログが同じSHA256であることをアプリが確認します。JSONを個別に読み込む方法も使えます。

起動できない場合

  • WindowsでPythonが見つからない場合、インストール後に起動ファイルを開き直してください。ターミナルなら py -3 -X utf8 launcher.py でも起動できます。
  • macOSで起動ファイルが開かない場合、ターミナルに bash と入力し、START_MAC.command をドラッグしてパスを入れ、Returnを押してください。Pythonを直接使う場合は python3 -X utf8 launcher.py です。
  • データフォルダを変える場合は python3 launcher.py --choose-folder（Windowsは py -3 launcher.py --choose-folder）を実行します。
  • 書き込みできない場所では、展開したフォルダを自分のドキュメントなどに移してから起動してください。

詳しい編集方法と出力形式は同梱の README.md を参照してください。
