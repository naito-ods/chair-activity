連続アノテーションの使い方

  1. 左から症例を選択し、記入者と対象範囲を確認します。
  2. タイムラインをドラッグして区間を選びます。右側で秒数を直接入力することもできます。
  3. 処置、器具、確認根拠、境界の確かさを記入し、「区間を反映して保存」を押します。
  4. 既存注釈は参考資料です。日本語の器具名を自動的に英語へ対応付けません。
  5. 未記入区間は「不明」にできます。「不明」と「処置なし」を区別してください。
  6. 記入者・未確認区間・重複・未記入のチェックを終えて「最終出力」を押します。下書きは途中でも出力できます。

器具は区間内に登場したものです。複数選択だけでは、同時使用や全区間での稼働を意味しません。

ログから推測した処置を、独立した臨床正解として扱わないでください。確認済みの臨床行為には動画・直接観察・診療記録の根拠を記入します。

保存履歴は毎回残ります。JSON再読込にはZIP内の annotations.json を使用してください。動画は保存されません。
